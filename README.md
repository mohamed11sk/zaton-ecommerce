**Overview**

Zaton is a simple e-commerce demo built with PHP, HTML, and CSS. It is intended as an educational starter project or a small shop prototype. It includes product pages, user login/signup, and a MySQL database dump (`zaton.sql`).

**Why you'll like it**

- ✨ Clean and easy-to-customize UI
- ⚡ Runs locally with XAMPP/WAMP
- 🗂️ Organized files to help you extend features quickly

**Main features**

- Product listing pages
- User authentication (login / signup)
- Ready-to-import database (`zaton.sql`)

---

**Requirements**

- `XAMPP` or any bundle that includes `Apache + PHP + MySQL`
- PHP 7.4 or newer

**Install & Run (Local)**

1. Place the project folder into your XAMPP `htdocs` directory (for example: `C:\xampp\htdocs\zaton-ecommerce`).
2. Start Apache and MySQL from the XAMPP control panel.
3. Open `phpMyAdmin` and import `zaton.sql` to create the database and tables.
4. Open your browser and go to:

```
http://localhost/zaton-ecommerce/index.php
```

---

**Project structure (short)**

- `index.php` — Home / entry page
- `login.php`, `signup.php` — Authentication pages
- `style.css`, `styles.css`, `login.css` — Design styles
- `zaton.sql` — Database dump to import
- `img/` — Product and logo images
